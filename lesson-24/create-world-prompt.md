# 需求：幫我蓋一個互動式 3D 作品集世界

請根據我附上的履歷，做一個互動式 3D 作品集：一座低多邊形（low poly）風格的漂浮小島樂園，每一個設施打開我履歷的一個區塊。介面跟內容用英文（給海外招募者看），程式註解用中文。

## 六個設施（可以增減，改名字也可以）

- 🎡 摩天輪＝職涯時間軸（Timeline）
- 🎢 雲霄飛車＝專案與成果（Projects，要有數字）
- 🌍 地球儀＝我住過、工作過、想去的地方（Places）
- 🌸 花園＝技能與語言（Skills）
- 🎪 帳篷＝有趣的點子、side project（Ideas：履歷裡沒有，先放清楚標示的預留內容，做完問我）
- 🪦 墓園＝失敗過的專案跟學到的事（Lessons：同上，先預留，做完問我）

## 技術要求（照做，不要自己換）

- 一個檔案：`index.html`，全部東西都在裡面。原生 JavaScript，不用 TypeScript，不用任何建置工具。
- three.js 用 ES module 從 CDN 載入，importmap 照這段寫：

```html
<script type="importmap">
{"imports":{"three":"https://cdn.jsdelivr.net/npm/three@0.186.0/build/three.module.js","three/addons/":"https://cdn.jsdelivr.net/npm/three@0.186.0/examples/jsm/"}}
</script>
```

- 不用任何外部模型檔、圖片、貼圖檔。所有東西用基本幾何體（方塊、圓錐、圓柱、球、管子）程式畫出來，flatShading 低多邊形風。用 Canvas 程式畫的貼圖可以（地球儀的地圖、招牌上的字）。
- 這個檔案要能**雙擊直接在瀏覽器打開**就跑，不能依賴本機伺服器。
- 手機也要能看：觸控拖曳、雙指縮放，側邊面板在手機上改成從底部彈出。
- 每一個設施寫在自己一個清楚註解的程式碼區塊裡。文字內容集中在檔案最上面一個 `CONTENT` 物件，方便我之後叫你改字不用動 3D。
- 計時用 `THREE.Timer`，不要用 `THREE.Clock`；陰影用 `PCFShadowMap`。（這兩個舊寫法在新版會跳棄用警告）

## 場景

- 漂浮小島：草地圓盤、泥土邊、底下岩石、幾朵慢慢飄的雲。中央小廣場，步道連到每個設施，路燈，入口大門有招牌，招牌用 Canvas 寫我的名字跟職稱。
- 設施要會動：摩天輪會轉，雲霄飛車有車在軌道上跑，帳篷旗子會飄，花園有螢火蟲，地球儀慢慢轉、我履歷裡的城市插紅色圖釘，墓園有薄霧跟提燈。

## 互動

- 拖曳旋轉、滾輪縮放。使用者 5 秒沒動，鏡頭慢慢自轉。
- 點設施、點設施上方的浮動標籤、或點底部導覽列：鏡頭滑過去，側邊面板打開那個區塊的內容。按 Esc 或關閉鈕關掉。面板打開的時候，右上角的按鈕還是要看得到、按得到。
- 六個浮動標籤不能互相重疊，疊到就往上推。
- 右上角三個按鈕：日／夜切換（夜晚整島點燈，點天空放煙火）、暫停動畫、Classic view（把所有內容變成一頁純文字，給不想看 3D 的人跟用手機的人）。
- 支援網址錨點 `#timeline`、`#projects` 這種，讓我可以直接分享某一區。

## 內容規則（最重要）

- 內容全部從我附的履歷來。**不可以捏造任何關於我的事實。**缺的、有疑問的，先問我，不要猜。
- 履歷裡的數字照抄，不要四捨五入、不要美化。
- 這個世界之後會公開放到網路上。**只放**：姓名、職稱、公司名、年份、成果數字、技能、語言、城市。**不放**：電話、地址、生日、證件號、簽證狀態、薪資。履歷裡如果有這些，跳過不放。LinkedIn 要放，email 不放。（要放 email 的人自己改這句）
- 不要把我的履歷檔複製進這個資料夾。

## 視覺

溫暖的嘉年華配色：磚橘、芥末黃、奶油白、深藍、草綠、天空藍。圓角、粗體的 UI。標題跟內文各用一個 Google Fonts 字型，載不到就退回系統字型。
