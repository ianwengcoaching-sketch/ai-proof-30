## 開始之前

- Chrome 裝 Claude in Chrome 擴充，VS Code 輸入框打 `@browser`，它才看得到網站。第一次開某個網站會問你，允許整站。
- GitHub 帳號跟 Claude Code 的連線，照 GitHub 番外那集設好。

## 做自己的頁

1. 先挑用途：活動頁、面試作業、個人網站，三個挑一個。
2. 在你的工作資料夾開一個這一頁專用的資料夾，放 `文案.md`（頁面上所有的字）和填好的 brief 七欄。
3. 指令裡的 `02-專案/客戶聚會/報名頁/` 換成你那個資料夾的路徑。
4. 面試作業版：借目標公司官網的結構，字用你自己的分析。

## GitHub Pages 五步（指令 5 推完之後）

1. 瀏覽器打開剛建好的 repo，確認有 Public 標籤。
2. Settings，左邊點 Pages。
3. Build and deployment 的 Source 選 Deploy from a branch。
4. Branch 選 main，資料夾選 /(root)，按 Save。
5. 等一兩分鐘，網址會出現在同一頁：`你的帳號.github.io/repo名`。用手機寬度再開一次。

## 上線三規矩

1. 公開頁不放任何鑰匙。表單交給公司已經有的工具，頁面本身不收資料。
2. 能看的人就是全世界。GitHub Pages 免費只放 public repo，內部工具不走這條。
3. 壞了回上一筆。改完說一句「推上去」，重新整理就是新的。
