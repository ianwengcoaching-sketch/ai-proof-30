# /voice：做一份你的語氣檔

你現在要帶使用者做一份 `voice.md`。全程繁體中文，中文標點一律全形，不用破折號。一次只問一件事，選項用 a／b／c 編號，讓他打一個字母就能回答。他答完才進下一步，不要一次把六步全部倒出來。

如果這個對話裡已經有一個 agent 身分（例如剛跑過 /pikachu），保持那個身分做這件事。**但步驟 0 的 a／b／c 一定要先問出來，不能替他選。**可以在題目後面加一句「我猜是 a，我就是你說的那個 agent」，然後停，等他回字母。

## 步驟 0：先問有沒有一個很懂他的 agent

這一則訊息只放這一題，三個選項各一行，問完就停。問：「你有沒有一個已經很懂你的 AI agent？a 有，我現在就在跟它講話／b 有，在檔案裡，我指給你看／c 沒有」

- a：把你記憶檔裡關於他的東西（身分、在做什麼、溝通偏好、硬規則）先整理成五行給他看，等一下訪談用來預填。
- b：請他給路徑，讀那些檔案，做同樣的整理。
- c：跳過，訪談會多問幾題。

說一句：有 agent 的人訪談會快很多，因為一半的題目它替你答。

五行給他看之後，問「這五行對嗎」就停，**等他回答再進步驟 1**，不要在同一則訊息裡先把步驟 1 的選項列出來。

## 步驟 1：餵真的文字

問他要用哪種方式給樣本：「a 直接貼文字或 @ 檔案給我／b 我去讀你已經連上的工具（Gmail、Notion、Drive）」

- 選 b 才去讀，而且只讀，不寫不寄。讀之前先講你要讀哪裡、讀多少。
- 目標三種：信（他真的寄出過的）、貼文（他自己一個字一個字敲的）、訊息（他跟朋友或粉絲講話的原文）。每種一到三份。
- 收到樣本前先講三條規矩：品質勝過數量，十二份很棒的勝過五十份普通的；挑他自己讀了會點頭的；**AI 幫他寫過的不能當樣本**，拿 AI 寫的餵你，你學到的是 AI。
- 樣本不夠三種也可以開始，但要說哪一種缺、之後補會更準。
- 樣本裡若有【】括起來的說明文字或空白範本，當作沒給，提醒他補。

## 步驟 2：講你看到什麼

讀完樣本，回他五到八條「我觀察到的習慣」，每條附一句原文當證據。看這些：句子長短的節奏、開場習慣、招牌轉折（例如「不是 X，是 Y」）、中英混用的方式、口頭禪與語尾、數字用不用、收尾怎麼收、標點習慣、emoji 與波浪號用不用。

不下評語，只講事實。最後問：「這幾條哪一條不準？」

## 步驟 3：封掉 AI 腔（黑名單六組）

一組一組出，每組問「全封、留幾個，還是要加」。預設清單：

1. 詞：賦能、抓手、閉環、深耕、助力、打造、擁抱、全方位、一站式、綜效
2. 句：「在這個快速變化的時代」「不僅僅是…更是…」「讓我們一起」「總而言之」「值得注意的是」「希望這對你有幫助」
3. 標點與格式：破折號（長的短的都算）、每段都加粗一個關鍵字、沒必要的項目符號、半形與全形標點混用
4. 句構：三項排比連發、每段一樣長、每句都對稱工整、每段結尾再補一句總結
5. 企業腔：把一句話講成一整段、「賦能團隊達成綜效」這類說法、「我建議您」這種客服口吻
6. 轉折堆疊：一句話裡塞兩個以上轉折，例如「然而，值得注意的是，同時也必須」

他加的規則照原話記，標「（自己加的）」。他要保留的詞也記下來，標「（保留）」。工作區裡若已經有反 AI 味清單（例如 anti-slop 技能），說一句「以 voice.md 這份為準，兩邊一致」，不要把那份重列一遍。

## 步驟 4：訪談補洞

先用步驟 0 與步驟 2 的材料預填，再一題一題確認。能預填的寫「我猜是…對嗎」，不能預填的才問。

1. 幽默開到幾格：1 到 5 給一個數字。追問：哪種場合要收斂
2. 什麼時候直白：哪些場合直接講，哪些場合先軟一句再講
3. 收尾與簽名：慣用的最後一句、要不要 emoji、用哪幾個、波浪號用不用
4. 你的絕不：三句他這輩子不會講的話
5. 反覆在講的觀點：三到五條（從樣本預填）
6. 好消息與壞消息各怎麼講：各一句
7. 分場合：求職信／LinkedIn 貼文／訊息與 DM／面試自我介紹，各一句口氣描述。**這題一定要問，不要猜。**

## 步驟 5：語氣卡、確認、存檔

把全部整理成一張「語氣卡」給他看，問：「像你嗎？哪一行不像？」改到他說「存」為止。

存檔規則：

- 有 agent（a 或 b）：存到那個 agent 的資料夾，檔名 `voice.md`；在該 agent 的載入檔加一行，讓它每次開對話都讀。以 Pikachu 為例：`Pikachu/CLAUDE.md` 加一行 `@voice.md`，`.claude/skills/pikachu/SKILL.md` 的讀檔清單加一行 `- Pikachu/voice.md`。
- 沒有 agent（c）：存到工作區根目錄 `voice.md`，並在根目錄 `CLAUDE.md` 加一行 `@voice.md`。
- **200 行以內。**超過就先刪重複的，再刪最不影響寫作結果的。
- 不寫進去：密碼、帳號、客戶姓名、任何他沒同意公開的數字。
- 存完回報三件事：檔案路徑、行數、加了哪一行載入。然後說：「Done。你的語氣已存檔並開啟。跑 /clear 開新對話，它就會用你的口氣寫。以後哪裡不像，跑 /update-voice。」

## voice.md 的格式（照這個寫，一節都不要多）

```
# voice.md：<名字>的語氣檔
_最後更新：<日期>_

## 一句話
（他是誰、對誰講話、講話的姿態，一句）

## 反覆在講的觀點
（三到五條）

## 句式指紋
（句長節奏、招牌轉折、中英混用規則、數字習慣、口頭禪與語尾，各附一句原文）

## 分場合
（求職信／LinkedIn／訊息與 DM／面試自介，各一句）

## 幽默與情緒
（幾格、哪裡收斂、好消息與壞消息怎麼講）

## 收尾與簽名
（最後一句、emoji、波浪號）

## 絕不
（三句）

## 黑名單（以此為準）
（六組，含「（自己加的）」與「（保留）」）

## 更新日誌
- <日期>：建立
```

每節用短句與條列，帶一兩句原文當例子。這份檔是給 AI 讀的，不是給人欣賞的：越具體越好，形容詞越少越好。
