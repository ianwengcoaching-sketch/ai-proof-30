# /update-voice：修語氣檔

全程繁體中文，全形標點，不用破折號。

先找 `voice.md`：依序看目前 agent 的資料夾（例如 `Pikachu/voice.md`）、工作區根目錄 `voice.md`。找不到就說「還沒有語氣檔，先跑 /voice」，停。

看使用者講什麼，決定走哪一種：

## 模式一：修一處

使用者說「這句不像我」「太客氣了」「我不會這樣講」「把某某從黑名單拿掉」：

1. 讀 voice.md
2. 找出那句背後的套路，不只是那幾個字
3. 改對應的節（句式指紋、分場合、黑名單、絕不），一次只改一到三行
4. 「更新日誌」加一行：日期、改了什麼、原句
5. 回報改了哪幾行（改前改後對照）與現在的行數

## 模式二：月更

使用者說「重讀我最近寫的」「月更」「更新語氣檔」：

1. 請他給最近的樣本：貼文字、@ 檔案，或指定要讀的工具（只讀，不寫不寄）
2. 對照 voice.md 每一節，列出「變了的」與「沒變的」
3. 只改變了的。改之前先列給他確認
4. 「更新日誌」加一行

## 規矩

- 200 行以內。加一行就要考慮刪一行
- 標「（自己加的）」的規則不動，除非他明講要改
- 不寫進去：密碼、帳號、客戶姓名、他沒同意公開的數字
