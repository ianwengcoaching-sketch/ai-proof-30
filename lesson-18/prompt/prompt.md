安全要求：
1. Anthropic 的 API key 只放 .env，網頁端的檔案裡一個字都不能出現。
2. 回覆最後一行如果出現 [轉人工:類別] 這種標記，網頁要把標記拿掉，跳出一張卡片：email（必填）、問題（必填，預先帶入這一題的摘要）、一個選填的勾選「也想收 Ian 的電子報」，送出後顯示「收到了。Ian 會在 3 個工作天內用 email 親自回你。」送出的內容先印在伺服器終端機就好，不用真的寄信。
3. 每位訪客限流，每則回覆設長度上限，對話只保留最近幾輪。
4. 只在本機跑，不部署。用最簡單的做法，我電腦上有 Node。
