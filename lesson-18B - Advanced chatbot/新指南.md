# 用Claude輕鬆建立品牌簡報AI Skill
網址：https://www.careergoglobal.com/guide/obMPfpWnydiWCFzaL

這大概是我在工作坊最常被問到的問題：「怎麼讓 AI 做出好看又符合品牌的簡報？」你當然可以用 Gamma 這類工具，但老實說，你只需要把 Claude「訓練」一次，它之後就能一直幫你產出漂亮的品牌簡報。這篇教你用「Skill」這個功能，把你的簡報風格變成 Claude 可以重複使用的規則——免費版或付費版都能用。

先搞懂「Skill」是什麼

- Skill 是你教給 Claude 的一套「規則」，它會記住並重複套用
- 你可以在左側選單的「Customize（自訂）」裡找到所有 Skill
- Claude 本來就內建一個做 PowerPoint 的 Skill，但我們要自己做一個專屬你品牌的
- 建好之後，給它資料、試算表、甚至模糊的想法，它就能產出符合品牌的簡報

步驟一

1

### 把你最好的投影片截圖下來

打開你做過最滿意的那份 PowerPoint，截圖幾張最好的投影片，或是你想保留的不同版型。重點是涵蓋各種版型，而不是同一種截好幾張。

> 建議截這幾種版型
> 封面標題頁、章節分隔頁、條列重點頁、圖表 / 數據頁。版型越完整，Claude 學到的規則就越完整。

如果你有「字型檔」和「品牌色 HEX 碼」，一起準備好，下一步會用到——這是讓簡報真正「像你的品牌」的關鍵。

步驟二

2

### 請 Claude 用截圖建立 Skill

開一個新的對話，把剛剛的截圖全部拖進去，再把字型檔和品牌色也一起附上，然後貼上這段指令：

▍建立 Skill Prompt
我想建立一個 Skill，用來產生符合我品牌風格的 PowerPoint 簡報。
請用我附上的這幾張投影片截圖來定義規則，包含：版面配置、字型、顏色、標題與內文的層級、圖表與卡片的樣式。
我也附上了我的字型檔，以及我的品牌色票如下：
【在這裡貼上你的品牌色 HEX 碼】
請根據這些素材建立 Skill。

> 為什麼有效
> 截圖讓 Claude「看見」你的設計語言，字型和色碼讓它精準重現。比起用文字描述「我要簡約一點」，直接給它範例，產出會接近你心中的樣子非常多。

步驟三 · 最關鍵

3

### 測試，然後一次列出所有要改的地方

Skill 建好後，Claude 可能會自動跑一個測試，做幾張投影片給你看。如果它沒有主動測試，你就請它做一份測試簡報：

▍測試 Skill Prompt
用這個 Skill 測試做一份 5 頁的簡報，主題是「社群媒體成效」。數字先隨便編沒關係，我只是想看看實際產出的樣子。

這會讓你看到它真正幫你工作時的樣子。一定會有些地方你不喜歡、需要調整，這很正常。接著把所有想改的地方一次列出來，在同一個對話裡改完，省時間：

▍微調 Skill Prompt
謝謝，幾個地方要修改：
1. 【你想改的第一件事，例如：標題字體再大一點】
2. 【第二件事，例如：封面背景換成深色】
3. 【第三件事，例如：圖表配色改用品牌橘】
請一次更新好。

> 為什麼有效
> 把修改集中在同一個對話裡，Claude 才有完整的上下文，不會改了 A 又忘了 B。持續微調，直到它做出來的東西讓你滿意為止。

步驟四

4

### 滿意了，就按「儲存 Skill」

當你終於滿意，按下「Save skill（儲存 Skill）」，它就會被存進我們一開始在 Customize 裡看到的 Skill 區。完成了。

> 從此之後
> 任何時候，你都可以丟給它試算表、原始數據、甚至只是一個模糊的方向讓它去研究，它就能幫你做出漂亮、品牌一致的簡報。一次設定，長期受用。

### 一個小提醒

第一次建出來的 Skill，幾乎不會一次到位，這完全正常。把它當成「調教」的過程——多花十分鐘把細節講清楚，換來的是之後每一份簡報都省下大把時間。

還有一件事：盡量在同一個對話裡把所有修改講完。分散在不同對話會讓 Claude 失去上下文，反而更費工。

常見問題

Q：免費版的 Claude 也能建 Skill 嗎？

可以。建立和使用 Skill 在免費版或付費版都能運作，這整套流程不需要付費功能。

Q：我沒有現成的漂亮簡報怎麼辦？

可以先用任何一份你覺得堪用的簡報截圖，或先告訴 Claude 你的品牌色和字型，請它做幾個版型給你挑，再從那裡開始調。

Q：Claude 不是已經會做 PowerPoint 了嗎？為什麼還要自己建？

內建的 Skill 做的是「通用」簡報。自己建一個，是為了讓每一份產出都自動套用你的品牌色、字型和版型，不用每次重講一遍。
