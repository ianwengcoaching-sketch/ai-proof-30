Claude Design 四段 demo 的練習檔跟指令，全部在這個資料夾。整個資料夾下載下來放一起，影片裡附檔的地方就從這裡拿。

## 借風格的清單

[awesome-claude-design](https://github.com/VoltAgent/awesome-claude-design) 整理了幾十套公開網站的視覺風格，每一套是一個 `DESIGN.md`。要借哪一套，就去 [awesome-design-md](https://github.com/VoltAgent/awesome-design-md) 下載那一套的 `DESIGN.md`，附檔上傳，再在指令裡說「用我附的風格檔」。這裡的 `Notion-DESIGN.md` 就是這樣拿來的（原專案 MIT 授權）。

風格可以借，商標不能用。這些檔案是照公開網站的視覺整理的，不是那些公司的官方檔案，不要放人家的 logo。

## 三條規矩

1. 先建系統，再做東西。
2. 圈起來改，不要重打。
3. 簡報下載 PPTX，網站下載 zip 搬進基地。
